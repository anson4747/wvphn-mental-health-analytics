This aihw-phc-23-csv-file-2017-18-to-2024-25-readme.txt accompanies the csv file for the 'Use of emergency departments for lower urgency care: 2017–18 to 2024–25' report. 


The file is intended for loading into analytical software for further analysis. They can be imported into a number of statistical software packages including SAS, R, or read by text editors including Notepad++. 

The aihw-phc-23-csv-file-2017-18-to-2024-25.csv file contains the following variables:
Code: Identifier for AIHW release
DataSource: Data source 
Name: Name of AIHW release
Worksheet: Identifier relating back to Excel download worksheet
Year: Reporting period
StateTerritory: State or Territory
GeographicUnit: Geographic area (NAT, RA, SEIFA, PHN or SA3)
GeographicCode: Code for geographic unit (i.e. PHN101, or 11101, etc.)
GeographicAreaName: Name of geographic area
GeographicGroup: Geographic group variable (National, Remoteness area, SEIFA quintile, PHN group or SA3 group)
DemographicGroup: Disaggregation (Male, Female, 0-24 years, etc.)
HourED: Time of ED presentation by hour in 24-hour time or as 'All-hours'
TriageCategory: Triage category (TC1+2,TC3,TC4,TC5,TC4+5 or All)
MeasureName: Name of measure
MeasureValue: Value of measure
Flag: Symbol used to flag a measure result
FlagExplanation: Explanation of the flag

The data sources for this report includes:

- National Non-Admitted Patient Emergency Department Care Database (NNAPEDCD), 2017-18 to 2024-25.
- Australian Bureau of Statistics, Estimated Resident Population (ERP) 30 June 2001 (age standardisation) and 30 June 2017 to 2024.

See aihw-phc-23-csv-file-2017-18-to-2024-25-metadata.xlsx and the technical notes in the web report for full details.
