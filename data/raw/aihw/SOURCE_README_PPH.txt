Please read this AIHW_PPH_1718_2324_ASGS3_README.txt file before using the AIHW_PPH_1718_2324_ASGS3.csv files.

This AIHW_PPH_1718_2324_README.txt accompanies the csv files for the 'Potentially preventable hospitalisations in Australia by small geographic areas, 2017–18 to 2023–24' report. 

There is 1 csv file: Data tables - machine readable - Potentially preventable hospitalisations 2017-18 to 2023-24.csv

The files are intended for loading into analytical software for further analysis. They can be imported into a number of statistical software packages including SAS, R, or read by text editors including Notepad++. 

The AIHW_PPH_1718_2324_ASGS3.csv files contains the following variables:
Code: Identifier for AIHW release
DataSource: Data source 
Name: Name of AIHW release
Worksheet: Identifier relating back to Excel download worksheet
Year: Reporting period
StateTerritory: State or Territory
GeographicUnit: Geographic area (NAT, RA, SEIFA, PHN or SA3)
GeographicCode: Code for geographic unit (i.e. PHN101, or 11101, etc.)
GeographicAreaName: Name of geographic area
GeographicGroup: Geographic group variable (National, Remoteness area, SEIFA quintile, PHN group or SA3 group)
DemographicGroup: Disaggregation (Male, Female, 0-64 years, etc.)
PPHGroup:PPH category (acute, chronic, vaccine-preventable, total separations etc.)
PPHCondition: PPH condition 
MeasureName: Name of measure
MeasureValue: Value of measure
Flag: Symbol used to flag a measure result
FlagExplanation: Explanation of the flag

The data sources for this report includes:

- National Hospital Morbidity Database (NHMD), 2017-18 to 2023-24.
- Australian Bureau of Statistics, Estimated Resident Population (ERP) 30 June 2001 (age standardisation) and 30 June 2017 to 2023.

See AIHW_PPH_1718_2324_ASGS3_metadata.xlsx and the technical notes in the web report for full details.
